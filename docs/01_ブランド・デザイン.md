# OWKR.GG ブランド・デザイン仕様

> ステータス：FIXED

このドキュメントは OWKR.GG のデザインルールを定義します。
すべてのページ・コンポーネントはこの仕様に従います。

---

# 1. デザインコンセプト

参考サイト：

- ohmygear.net（韓国デバイスデータサイト）

OWKR.GG のコンセプトは

> 「ゲームメディアではなく、洗練されたeスポーツデータベース」

キーワード

- ミニマル
- 高級感
- 読みやすい
- 軽量
- 情報中心

派手な装飾より情報を主役にする。

---

# 2. ブランドアイデンティティ

サイト名

OWKR.GG

サブタイトル

韓国Overwatchプロデータベース

サイトUI

日本語

選手名

英語表記（Proper, Lip, Hanbin...）

韓国名

補足情報として表示。

---

# 3. カラーパレット

ベースカラーはグレーのみ。

| トークン | 用途 |
|-----------|------|
| Background | ページ背景 |
| Surface | カード背景 |
| Surface Secondary | サブカード |
| Border | 枠線 |
| Text Primary | 本文 |
| Text Secondary | 補足 |

---

## アクセントカラー

アクセントカラーを使う場所は限定する。

| 用途 | 使用可 |
|------|----------|
| Team Badge | ○ |
| Brand Badge | ○ |
| Role Badge | ○ |
| リンク | ○ |
| ページ背景 | × |
| カード背景 | × |

---

# 4. ロールカラー

固定色。

| ロール | 用途 |
|---------|------|
| Tank | Badgeのみ |
| DPS | Badgeのみ |
| Support | Badgeのみ |

カード背景には使わない。

---

# 5. タイポグラフィ

| 要素 | 太さ |
|-------|------|
| ページタイトル | Bold |
| セクションタイトル | Semibold |
| カードタイトル | Semibold |
| 本文 | Regular |
| 補足情報 | Regular |

ルール

- 過度に大きい文字は禁止。
- 行間を広めに取る。
- 余白で見やすさを作る。

---

# 6. レイアウト

共通ルール

- モバイルファースト
- 最大幅を固定
- 左右余白は共通
- セクション間余白を広めにする

---

## モバイル

- 縦積みレイアウト。
- カードは1列。
- ランキング・ショート動画は横スクロール。

---

## デスクトップ

- 中央寄せ。
- 最大幅コンテナ。
- 必要な場所のみ2〜4列グリッド。

---

# 7. Header

表示内容

- OWKR.GG ロゴ
- Players
- Teams
- Devices
- Brands
- Rankings
- 検索
- テーマ切替

仕様

- Sticky Header
- スクロールで背景表示

---

# 8. Footer

表示内容

- ナビゲーション
- コピーライト
- アフィリエイト表記
- 最終更新日

フッターは控えめなデザイン。

---

# 9. カードデザイン

全カード共通仕様。

| 項目 | 仕様 |
|------|------|
| 背景 | Surface |
| 枠線 | Border |
| 角丸 | 共通 |
| シャドウ | 共通 |

カードごとに色を変えない。

---

# 10. ボタンデザイン

ボタンは3種類のみ。

| ボタン | 用途 |
|----------|------|
| Primary | Amazon・検索など主要操作 |
| Secondary | 一覧を見る |
| Ghost | SNS・小さい操作 |

Primaryだけアクセント色を使える。

---

# 11. バッジデザイン

使用するバッジ。

- Team
- Brand
- Role
- Hero
- Published
- 情報確認中

すべて Pill型。

---

# 12. アイコン

アイコンライブラリ

Lucide Icons のみ使用。

複数ライブラリは禁止。

---

# 13. 画像ルール

| 画像 | 比率 |
|------|------|
| 選手 | 1:1 |
| デバイス | 1:1 |
| ヒーロー | 1:1 |
| チームロゴ | SVG推奨 |
| ブランドロゴ | SVG推奨 |

画像形式

WebP 推奨。

---

# 14. アニメーション

許可

- Hover
- Fade
- Theme Transition
- 小さなScale

禁止

- 自動アニメーション
- 派手なエフェクト
- 点滅

---

# 15. レスポンシブルール

スマホを最優先。

PCでは情報量を増やすだけで構造は変えない。

---

# 16. デザインチェックリスト

すべてのページは以下を満たす。

- 日本語UI
- 英語選手名
- ダークモード対応
- ライトモード対応
- モバイル対応
- グレーベース
- アクセントカラーは情報表示のみ
- 共通カードを使用する
