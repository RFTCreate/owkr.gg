# OWKR.GG チームページ仕様

> ステータス：FIXED

チームページは所属選手を一覧で見られるページ。

チーム紹介やニュースではなく、選手データへの入口として設計する。

---

# 1. ページの目的

チームページでは以下を提供する。

- 現所属選手一覧
- ロールごとの選手一覧
- チーム使用デバイスランキング
- チーム所属選手ページへの導線

---

# 2. URL仕様

例

/teams/team-falcons
/teams/t1
/teams/gen-g
/teams/crazy-raccoon

slug は英語のみ。

# 5. HeroCard仕様

表示項目

| 項目 | 必須 |
|------|------|
| チームロゴ | ○ |
| チーム名 | ○ |
| 所属人数 | ○ |

チーム説明文は掲載しない。

---

# 6. ロール別所属選手

表示順は固定。

1. Tank
2. DPS
3. Support

各選手カード表示内容

- 顔写真
- 英語名
- ロールバッジ

クリックで選手ページへ。

---

# 7. チーム使用デバイスランキング

所属選手が使用しているデバイスを集計する。

カテゴリ

- Mouse
- Keyboard
- Mousepad
- Monitor
- Audio

表示内容

- 商品画像
- 商品名
- 使用人数

ランキングページへリンクする。

---

# 8. 最新Shorts

そのチーム所属選手の Shorts を表示する。

最大6本。

表示内容

- サムネイル
- タイトル
- 選手名
- 投稿日
