# OWKR.GG 検索仕様

> ステータス：FIXED

OWKR.GG の検索機能・検索対象・表記揺れ対応を定義する。

---

# 1. 検索の目的

ユーザーが「誰を探したいか」を最短で見つけられる検索を目指す。

検索対象は選手・チーム・デバイス・ブランド。

---

# 2. 検索対象

| 対象 | MVP |
|------|-----|
| 選手名 | ○ |
| チーム名 | ○ |
| デバイス名 | ○ |
| ブランド名 | ○ |
| メインヒーロー | ×（Phase2） |

---

# 3. 検索バー

プレースホルダー

> 選手名・チーム名・デバイス名を検索

ヘッダーとトップページの両方に設置する。

---

# 4. 選手検索

以下のすべてでヒットする。

| 入力例 | Proper が表示される |
|--------|---------------------|
| Proper | ○ |
| proper | ○ |
| PROPER | ○ |
| プロパー | ○ |
| 프로퍼 | ○ |

大文字・小文字は区別しない。

---

# 5. 日本語表記揺れ対応

`search_aliases` テーブルで管理する。

例

| 正式選手 | エイリアス |
|-----------|-----------|
| Proper | プロパー |
| Proper | ぷろぱー |
| Lip | リップ |
| Hanbin | ハンビン |
| Viol2t | バイオレット |

検索結果は正式ページへ遷移する。

---

# 6. 韓国語検索対応

韓国語名でも検索できる。

例

| 入力 | 表示 |
|------|------|
| 프로퍼 | Proper |
| 립 | Lip |
| 한빈 | Hanbin |
| 슈 | Shu |

---

# 7. チーム検索

チーム名・略称の両方に対応する。

例

| 入力 | 表示 |
|------|------|
| Falcons | Team Falcons |
| Team Falcons | Team Falcons |
| T1 | T1 |
| CR | Crazy Raccoon |

---

# 8. デバイス検索

商品名・ブランド名の両方に対応する。

例

| 入力 | 表示 |
|------|------|
| Superlight | Logitech G PRO X Superlight 2 |
| GPRO | Logitech G PRO X Superlight 2 |
| Wooting | Wooting 60HE |
| Artisan Zero | ARTISAN ZERO |

---

# 9. ブランド検索

ブランドページへ遷移する。

例

- Logitech
- Logicool
- Razer
- BenQ ZOWIE
- SteelSeries
- Wooting

---

# 10. 検索結果表示順

優先順位は固定。

1. Players
2. Teams
3. Devices
4. Brands

同じカテゴリ内は前方一致を優先する。

---

# 11. 検索結果カード

## Players

表示

- 顔写真
- 英語名
- チーム
- ロール

## Teams

表示

- ロゴ
- チーム名

## Devices

表示

- 商品画像
- ブランド
- 商品名

## Brands

表示

- ロゴ
- ブランド名

---

# 12. 検索一致ルール

一致方式

- 前方一致
- 部分一致
- エイリアス一致

MVPではあいまい検索（typo補正）は実装しない。

---

# 13. 検索結果なし

表示文言

> 該当するデータが見つかりませんでした。

候補表示

- 人気選手
- 人気デバイス

---

# 14. URL仕様

検索ページ

/search?q=proper

検索キーワードはURLクエリで保持する。
