# OWKR.GG 共通コンポーネント仕様

> ステータス：FIXED
>
> OWKR.GG 全ページで使用する UI コンポーネントの仕様を定義する。

---

# 1. コンポーネント設計方針

OWKR.GG は **カードベースUI** を採用する。

ルール

- 1コンポーネント = 1役割。
- 同じ見た目は必ず使い回す。
- ページ専用カードは作らない。
- すべてライトモード・ダークモード対応。

---

# 2. 採用コンポーネント一覧

| コンポーネント | 用途 |
|---|---|
| HeroCard | ページ最上部 |
| SummaryCard | 30秒で分かる概要 |
| ProfileCard | 基本プロフィール |
| MainHeroCard | メインヒーロー |
| SettingsCard | ゲーム設定 |
| DeviceCard | デバイス情報 |
| AchievementCard | 実績 |
| SameDevicePlayersCard | 同じデバイスの選手 |
| SameTeamPlayersCard | 同じチームの選手 |
| ShortsCard | YouTube Shorts |
| SNSCard | SNS一覧 |
| UpdateCard | 最終更新情報 |
| RankingCard | ランキング表示 |
| Badge | バッジ |
| Button | ボタン |
| SectionHeader | セクション見出し |

この一覧以外のカードは仕様追加なしでは作成しない。

---

# 3. HeroCard

ページ最上部のカード。

## 表示項目

- 選手画像
- 英語名
- 韓国語名
- チームバッジ
- ロールバッジ
- メインヒーローバッジ
- 情報ステータス

## レイアウト

### モバイル

画像 → テキスト

### PC

画像左・情報右

## 表示しないもの

- デバイス
- 感度
- 実績
- SNS

---

# 4. SummaryCard ⭐

YouTube Shorts から来たユーザー向けの概要カード。

HeroCard の直下に配置する。

## 表示項目

| 項目 | 必須 |
|---|---|
| 所属チーム | ○ |
| ロール | ○ |
| メインヒーロー | ○ |
| 使用マウス | ○ |

## 仕様

- メインヒーローは最大3体。
- マウス名は DevicePage にリンク。
- Amazon ボタンは表示しない。
- 全選手ページ共通。

---

# 5. ProfileCard

プロフィールカード。

## 表示項目

| 項目 | 必須 |
|---|---|
| 英語名 | ○ |
| 韓国語名 | ○ |
| 所属チーム | ○ |
| ロール | ○ |
| 国籍 | ○ |
| 生年月日 | 任意 |
| 活動状況 | ○ |

## 表示しないもの

- 長いプロフィール文
- チーム履歴
- 配信サイト一覧

---

# 6. MainHeroCard

メインヒーロー一覧。

## 表示項目

- ヒーローアイコン
- 日本語名

## 仕様

- 最大5体。
- 左から重要順。
- 統計は掲載しない。

---

# 7. SettingsCard

ゲーム設定カード。

## 表示項目

| 項目 |
|---|
| DPI |
| Sensitivity |
| eDPI |
| Scoped Sensitivity |
| Polling Rate |

## ルール

- eDPI は自動計算。
- 不明なら「情報確認中」。
- 推測は禁止。

---

# 8. DeviceCard

OWKR.GG の最重要カード。

## 表示項目

- デバイス画像
- ブランドロゴ
- 製品名
- カテゴリ
- 使用選手数
- Amazonボタン

## ボタン

文言：Amazonで見る

## 表示しないもの

- 価格
- レビュー
- 評価
- 星

DeviceCard は全ページ共通で使い回す。

---

# 9. AchievementCard

主要実績を表示する。

## 表示項目

- 大会名
- 順位
- 年

## 仕様

- 最大5件。
- 新しい順。

---

# 10. SameDevicePlayersCard

同じデバイスを使用する韓国プロ。

## 表示項目

- 選手画像
- 英語名
- チーム
- ロール

最大6人。

---

# 11. SameTeamPlayersCard

同じチームの選手一覧。

## 表示項目

- 選手画像
- 英語名
- ロール

現所属メンバーのみ表示。

---

# 12. ShortsCard

YouTube Shorts 一覧。

## 表示項目

- サムネイル
- タイトル
- 投稿日

## 仕様

- 最大6本。
- 新しい順。
- PlayerPage 内では埋め込み表示可能。

---

# 13. SNSCard

公式SNS一覧。

## 対応サービス

- X
- YouTube
- Twitch
- CHZZK
- Instagram
- AfreecaTV

公式URLのみ掲載。

---

# 14. UpdateCard

情報更新カード。

## 表示項目

- 最終更新日
- 公開ステータス

ステータス

- Published
- 情報確認中

Draft は公開しない。

---

# 15. RankingCard

ランキング専用カード。

## 表示項目

- 順位
- デバイス画像
- デバイス名
- 使用人数
- 使用率

ランキングページ専用。

Amazonボタンは表示しない。

---

# 16. Badge

使用するバッジ。

| バッジ | 用途 |
|---|---|
| Team | チーム |
| Brand | ブランド |
| Role | ロール |
| Hero | メインヒーロー |
| Published | 公開済み |
| 情報確認中 | 未確認 |

Pill型で統一。

---

# 17. Button

3種類のみ採用。

| ボタン | 用途 |
|---|---|
| Primary | Amazon・検索 |
| Secondary | 一覧を見る |
| Ghost | SNS・補助操作 |

サイズ

- Small
- Medium
- Large

---

# 18. SectionHeader

全ページ共通見出し。

## 表示項目

- タイトル
- 説明（任意）
- ボタン（任意）

ページごとにデザイン変更しない。

---

# 19. Empty State

情報がない場合の表示。

表示文言

情報確認中

空欄・ダミーデータは禁止。

---

# 20. コンポーネント共通ルール

すべてのコンポーネントは以下を満たす。

- モバイル対応
- PC対応
- ダークモード対応
- ライトモード対応
- TypeScript Props 化
- 再利用可能
- ページ固有の見た目を持たない
