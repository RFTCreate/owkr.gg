# OWKR.GG 選手ページ仕様

> ステータス：FIXED
>
> OWKR.GG の中心ページ。YouTube Shorts から流入したユーザーが最も利用するページ。

---

# 1. ページの目的

選手ページは「30秒で概要が分かり、3分でその選手を理解できる」ことを目的とする。

役割は以下の4つ。

- 選手を紹介する。
- 使用デバイスを紹介する。
- ゲーム設定を掲載する。
- Shorts・関連選手へ誘導する。

---

# 2. URL仕様

各選手に1ページ。

例

/players/proper
/players/lip
/players/hanbin

URLは英語IDのみ使用する。

# 5. HeroCard仕様

ページ最上部。

## 表示項目

| 項目 | 必須 |
|------|------|
| 選手画像 | ○ |
| 英語名 | ○ |
| 韓国語名 | ○ |
| チームバッジ | ○ |
| ロールバッジ | ○ |
| メインヒーローバッジ | ○ |
| 情報ステータス | ○ |

HeroCardにはデバイス情報を表示しない。

---

# 6. SummaryCard仕様 ⭐

HeroCard直下に固定配置。

## 表示項目

| 項目 | 必須 |
|------|------|
| 所属チーム | ○ |
| ロール | ○ |
| メインヒーロー（最大3） | ○ |
| 使用マウス | ○ |

## ルール

- マウスは DevicePage にリンク。
- Amazon ボタンなし。
- 全選手ページ共通。

---

# 7. ProfileCard仕様

## 表示項目

| 項目 | 必須 |
|------|------|
| 英語名 | ○ |
| 韓国語名 | ○ |
| 所属チーム | ○ |
| ロール | ○ |
| 国籍 | ○ |
| 生年月日 | 任意 |
| 活動状況 | ○ |

長文プロフィールは掲載しない。

---

# 8. MainHeroCard仕様

## 表示内容

- ヒーローアイコン
- 日本語ヒーロー名

最大5体。

重要順に並べる。

統計値は掲載しない。

---

# 9. SettingsCard仕様

## 表示項目

| 項目 |
|------|
| DPI |
| Sensitivity |
| eDPI |
| Scoped Sensitivity |
| Polling Rate |

## ルール

- eDPI は自動計算。
- 情報が無ければ「情報確認中」。
- 推測値は禁止。

---

# 10. DeviceSection仕様

表示順は固定。

1. Mouse
2. Keyboard
3. Mousepad
4. Monitor
5. Audio Device

すべて DeviceCard を使用する。

---

# 11. DeviceCard仕様

表示項目

- 商品画像
- ブランド
- 製品名
- カテゴリ
- 使用プロ人数
- Amazonで見るボタン

価格・レビュー・評価は掲載しない。

---

# 12. AchievementCard仕様

表示項目

- 大会名
- 順位
- 年

最大5件。

新しい順。

---

# 13. SameDevicePlayersCard仕様

タイトル例

同じマウスを使用している韓国プロ

表示内容

- 顔写真
- 英語名
- チーム
- ロール

最大6人。

---

# 14. SameTeamPlayersCard仕様

表示内容

- 顔写真
- 英語名
- ロール

現所属メンバーのみ表示。

最大6人。

---

# 15. ShortsCard仕様

表示数

最大6本。

表示内容

- サムネイル
- タイトル
- 投稿日

クリックで YouTube Shorts を開く。

---

- CHZZK

# 17. UpdateCard仕様

表示項目

- 最終更新日
- 情報ステータス

ステータス

- Published
- 情報確認中

# 19. モバイル・PC仕様

## モバイル

- 全カード縦積み。
- DeviceCard は1列。
- Related Players は横スクロール。
- Shorts は横スクロール。

## PC

- HeroCard は2カラム。
- DeviceCard は2列グリッド。
- Related Players は3列。
- Shorts は3列。
