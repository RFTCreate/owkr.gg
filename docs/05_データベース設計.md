# OWKR.GG データベース設計

> ステータス：FIXED

OWKR.GG の Supabase データベース構造を定義する。

この仕様を変更する場合は仕様書を更新してから実装する。

---

# 1. 設計方針

OWKR.GG は **正規化 + 再利用** を優先する。

ルール

- 選手はデバイスIDのみ保持する。
- デバイス情報は1箇所だけ管理する。
- チーム情報は1箇所だけ管理する。
- Amazonリンクはデバイスのみ保持する。
- eDPI は保存せず自動計算する。

---

# 2. テーブル一覧

| テーブル | 用途 |
|----------|------|
| players | 選手情報 |
| devices | デバイス情報 |
| teams | チーム情報 |
| brands | ブランド情報 |
| shorts | YouTube Shorts |
| search_aliases | 日本語・韓国語検索用 |

MVPではこの6テーブルのみ採用する。

---

# 3. ER図（MVP）

brands
└── devices
        ▲
        │
players ───────── shorts
   │
   ▼
teams

- brands → devices（1対多）
- teams → players（1対多）
- players → shorts（1対多）
- players → devices（多対1）
